# AI-ML-Biomed

A professional learning and development workspace for **Biomedical Engineering, Artificial Intelligence, Machine Learning, Deep Learning, Medical Imaging, and Biomedical Signal Processing**.

This repository tracks my progress toward building practical biomedical AI applications, from Python fundamentals to deep learning research.

## 🛠️ Environment

- **Python:** 3.13
- **Numerical computing:** NumPy, SciPy
- **Data analysis:** Pandas
- **Visualization:** Matplotlib
- **Image processing:** OpenCV
- **Machine learning:** scikit-learn
- **Deep learning:** PyTorch
- **GPU acceleration:** CUDA
- **GPU:** NVIDIA GeForce RTX 2080 Max-Q
- **Development:** VS Code, Git, GitHub, pytest, Ruff

## 📁 Project Structure

## 🧪 Testing and Code Quality

Run the automated tests:

```bash
python -m pytest
```

Check code quality:

```bash
python -m ruff check .
```

Check code formatting:

```bash
python -m ruff format --check .
```
